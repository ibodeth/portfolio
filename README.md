# Developer Portfolio

Personal website and developer portfolio featuring systems engineering and software projects.

## How it Works
A retro-themed web application that loads a system boot sequence using Web Audio APIs and displays interactive bento grid components.

## Tech Stack
- **Languages/Frameworks:** React 18, Vite, TypeScript
- **Services/Libraries:** Tailwind CSS
- **Infrastructure:** Docker, Docker Compose

## Quick Start (Docker)
```bash
docker compose up -d --build
```

## Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ibodeth/portfolio.git
   cd portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
